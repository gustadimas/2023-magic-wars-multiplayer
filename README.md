# Magic Wars

Isso é de out/2023 a nov/2023, da época da faculdade. Coloquei no GitHub em 2026 como registro e deixei como estava.

Jogo 2D multiplayer online com Photon PUN 2. Tem tela de loading, menu, lobby pra criar ou entrar em sala e a partida, com vida, tiros, temporizador e mensagens de feed na tela. Os scripts do jogador estão em `Assets/Scripts/Player` e os de rede em `Assets/Scripts/Multiplayer`.

Tirei o App ID do Photon antes de subir. Pra rodar, crie um App ID grátis no painel da Photon e coloque em `Assets/Photon/PhotonUnityNetworking/Resources/PhotonServerSettings.asset`.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.18f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

## Créditos

Photon PUN 2 e TextMesh Pro. Sprites e animações em `Assets/Resources` e `Assets/Tiles&Anims`.
